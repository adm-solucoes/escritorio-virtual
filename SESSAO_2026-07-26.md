**O que foi feito:**

## 6. Bug de rolagem no WhatsApp/Instagram

**Pedido:** "as mensagem descem lá pra baixo... não tem uma parte de
rolagem que nem sites normais".

**Causa raiz:** o container de conversas não tinha altura travada no
navegador (só `flex-1`, sem `min-h-0` nem altura fixa) — então quando a
conversa tinha muitas mensagens, em vez da área de mensagens ganhar rolagem
própria, a página inteira crescia e o navegador rolava tudo.

**Correção:** `src/app/whatsapp/page.tsx` e `src/app/instagram/page.tsx` —
container principal com `h-[calc(100dvh-56px)] md:h-dvh` + `min-h-0`
propagado pelos filhos flex. Testado e confirmado: a área de mensagens
agora rola por dentro, o resto da página fica fixo.

**Estado:** publicado.

## Como publicar (padrão usado a sessão toda)

```bash

npx tsc --noEmit -p tsconfig.json   # typecheck
npx eslint <arquivos alterados>     # lint
npm run build                       # build completo
npx vercel --prod --yes             # deploy
```

Sempre commitar antes de publicar (`git add` + `git commit`), nunca usar
`git push` (este repo não tem remoto — o deploy é direto via Vercel CLI).
